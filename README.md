# 🪷 บันทึกใจ

เว็บแอปสำหรับจดบันทึกอารมณ์ประจำวัน บันทึกการเดินจงกรม และติดตามการปฏิบัติตาม **หลักธรรมนาวา “วัง” 7 ขั้นตอน**

- เขียนด้วย **Flask** ทั้งหมดอยู่ในไฟล์เดียว (`app.py`)
- ตกแต่งด้วย **Tailwind CSS (CDN)**
- เก็บข้อมูลด้วย **SQLite** (ไฟล์ `mindful.db` สร้างให้อัตโนมัติ)

## การติดตั้งและรัน

### 1. ติดตั้ง Flask

แนะนำให้สร้าง virtual environment ก่อน (ไม่บังคับ)

**Windows (PowerShell)**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install flask
```

**macOS / Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install flask
```

### 2. รันเว็บ

```bash
python app.py
```

### 3. เปิดเบราว์เซอร์

ไปที่ **http://127.0.0.1:5000**

> หยุดการทำงานด้วยการกด `Ctrl + C` ในหน้าต่าง Terminal

## วิธีใช้งานแต่ละหน้า

แถบเมนูด้านบนมี 4 หน้า

### 🏠 หน้าหลัก

สรุปภาพรวมการปฏิบัติ

| ส่วน | รายละเอียด |
|---|---|
| การ์ดสรุปวันนี้ | อารมณ์เฉลี่ย · นาทีเดินจงกรม · ขั้นตอนธรรมนาวาที่ทำแล้ว (x/7) · จำนวนวันที่ปฏิบัติต่อเนื่อง |
| ภาพรวม 7 วันล่าสุด | อีโมจิอารมณ์เฉลี่ย · แถบนาทีเดินจงกรม · จุด 7 จุดแทนขั้นตอนที่ทำ (กดที่จุดเพื่อไปยังวันนั้น) |
| บันทึกอารมณ์ล่าสุด | แสดง 4 รายการล่าสุด |

> “ปฏิบัติต่อเนื่อง” จะนับวันที่มีการบันทึกอย่างใดอย่างหนึ่ง (อารมณ์ / เดินจงกรม / ติ๊กขั้นตอน)

### 📝 บันทึกอารมณ์

ใช้ประกอบ **ขั้นที่ 2 ทักอารมณ์**, **ขั้นที่ 6 จับอารมณ์ลงขันธ์** และ **ขั้นที่ 7 พิจารณาลงอริยสัจ 4**

1. เลือก **วันที่** และ **เวลา** (ค่าเริ่มต้นคือตอนนี้)
2. เลือก **ระดับความรู้สึก** 😢 😟 😐 🙂 😄
3. เลือก **อารมณ์ที่เกิดขึ้น** เช่น โกรธ กังวล สุข
   → ระบบจะแสดงประโยค **ทักอารมณ์** ให้ทันที เช่น
   *นี่คือ “ความกังวล” · “ความกังวล” กำลังเกิดขึ้นกับจิต · …*
4. เขียน **เหตุที่ทำให้อารมณ์เกิด**
5. **จับอารมณ์ลงขันธ์** — เลือกได้หลายข้อ (รูป เวทนา สัญญา สังขาร วิญญาณ)
6. **ดูขันธ์ 5 เกิด–ดับ** — เขียนสิ่งที่เห็นขณะเฝ้าดูอารมณ์จนดับไป
7. **พิจารณาขันธ์ 5 ลงอริยสัจ 4** — ระบบแสดงแนวทาง ทุกข์ / สมุทัย / นิโรธ / มรรค ตามอารมณ์ที่เลือก แล้วเขียนสิ่งที่พิจารณาเห็น
8. กด **บันทึกอารมณ์**

ด้านขวาของหน้า

- **อารมณ์ที่พบบ่อยใน 30 วัน** — กราฟแท่งสรุป
- **บันทึกล่าสุด** — เลือกวันที่เพื่อดูเฉพาะวันนั้น · กด 🗑️ เพื่อลบ

### 👣 เดินจงกรม

**ใช้ตัวจับเวลา**

1. เลือกเวลา 10 / 15 / 20 / 30 / 45 / 60 นาที
2. เลือก **พิจารณาขั้นตอนใดขณะเดิน** (ไม่บังคับ) — จะแสดงสาระของขั้นนั้นไว้เตือนใจ
3. กด **▶ เริ่ม** · **⏸ พัก** · **↺ รีเซ็ต** ได้ตามต้องการ
4. เมื่อครบเวลา จะมี **เสียงระฆัง 3 ครั้ง** และกรอกนาทีกับขั้นตอนลงฟอร์มให้อัตโนมัติ

> หากหยุดก่อนครบเวลา กด **“ใช้เวลาที่เดินไปแล้วกรอกลงฟอร์ม”** เพื่อบันทึกเวลาที่เดินจริง

**บันทึกผล**

| ช่อง | ความหมาย |
|---|---|
| วันที่ / เวลา (นาที) | วันและระยะเวลาที่เดิน |
| พิจารณาขั้นตอน | ขั้นตอนใดใน 7 ขั้นที่ใช้พิจารณาขณะเดิน |
| รอบ | จำนวนรอบไป–กลับ (ไม่บังคับ) |
| พิจารณาเรื่องใดขณะเดิน | เช่น พิจารณาความโกรธเมื่อเช้าลงขันธ์ 5 |
| สภาวะที่พบ | เช่น ฟุ้งซ่านช่วงแรก แล้วค่อยๆ สงบ |

ด้านขวาของหน้าแสดงสถิติว่าแต่ละขั้นตอนถูกพิจารณาขณะเดินไปกี่ครั้ง / กี่นาที และประวัติการเดินทั้งหมด

### 📿 ธรรมนาวา 7 ขั้น

1. ระลึกพระรัตนตรัย
2. ทักอารมณ์
3. ท่องธาตุกัมมัฏฐาน 4
4. พิจารณาร่างกาย 6 ขั้นตอน
5. ท่องขันธ์ 5 / แยกขันธ์ 5
6. ดูขันธ์ 5 เกิดดับ / จับอารมณ์ลงขันธ์
7. พิจารณาขันธ์ 5 ลงอริยสัจ 4

**วิธีใช้**

1. เลือกวันที่ด้านบน (ปุ่ม ‹ › เพื่อเลื่อนวัน)
2. กด **อ่านรายละเอียด** ใต้แต่ละขั้น เพื่ออ่านวิธีปฏิบัติ / บทท่อง
   (หรือกด **เปิดรายละเอียดทั้งหมด** ที่แถบด้านบน)
3. **ติ๊ก ☑** ขั้นตอนที่ปฏิบัติแล้ว — แถบความคืบหน้าจะอัปเดตทันที
4. เขียน **สิ่งที่ได้พิจารณา / ความเข้าใจที่เกิดขึ้นวันนี้**
5. กด **💾 บันทึกการปฏิบัติ**

> ⚠️ การติ๊กยังไม่ถูกบันทึกจนกว่าจะกดปุ่ม **บันทึกการปฏิบัติ**

**🙈 โหมดฝึกท่อง (ขั้นที่ 3)**

บทธาตุกัมมัฏฐาน 4 ต้อง “ท่องให้ได้แบบทุกตัวอักษร”

1. เปิดรายละเอียดขั้นที่ 3
2. กด **🙈 ซ่อนข้อความเพื่อฝึกท่อง** — ข้อความจะเบลอ
3. ท่องทีละย่อหน้า แล้ว **แตะที่ย่อหน้า** เพื่อเฉลยตรวจความถูกต้อง
4. กด **👀 แสดงข้อความทั้งหมด** เพื่อกลับเป็นปกติ

**แถบด้านขวา**

- จำนวนบันทึกอารมณ์ และนาทีเดินจงกรมของวันที่เลือก
- ตาราง **14 วันล่าสุด** — สีเทา = 0 · เหลืองอ่อน = 1–3 · เหลืองเข้ม = 4–6 · เขียว = ครบ 7

## ข้อมูลและการสำรองข้อมูล

- ข้อมูลทั้งหมดอยู่ในไฟล์ **`mindful.db`** โฟลเดอร์เดียวกับ `app.py`
- **สำรองข้อมูล:** คัดลอกไฟล์ `mindful.db` เก็บไว้ (ควรหยุดเว็บก่อนคัดลอก)
- **กู้คืน:** นำไฟล์ที่สำรองไว้มาวางแทนที่
- **เริ่มใหม่ทั้งหมด:** ลบไฟล์ `mindful.db` แล้วรันเว็บใหม่
- อัปเดต `app.py` เป็นเวอร์ชันใหม่ได้โดยไม่ต้องลบข้อมูล — ระบบจะเพิ่มคอลัมน์ใหม่ให้อัตโนมัติ

**ตารางในฐานข้อมูล**

| ตาราง | เก็บอะไร |
|---|---|
| `moods` | บันทึกอารมณ์ (ระดับ, อารมณ์, เหตุ, ขันธ์, เกิด–ดับ, อริยสัจ 4) |
| `walks` | การเดินจงกรม (นาที, ขั้นตอนที่พิจารณา, เรื่องที่พิจารณา, รอบ, สภาวะ) |
| `practice` | การปฏิบัติ 7 ขั้นตอนรายวัน (ขั้นที่ทำ, สิ่งที่ได้พิจารณา) |

## การตั้งค่า

ตั้งค่าผ่าน environment variable (ไม่บังคับ)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `MINDFUL_DB` | `mindful.db` (ข้าง `app.py`) | ตำแหน่งไฟล์ฐานข้อมูล |
| `SECRET_KEY` | `dev-change-me` | คีย์สำหรับ session / ข้อความแจ้งเตือน |

ตัวอย่าง (Windows PowerShell)

```powershell
$env:MINDFUL_DB = "D:\backup\mindful.db"
python app.py
```

ตัวอย่าง (macOS / Linux)

```bash
MINDFUL_DB=~/mindful.db python app.py
```

**เปลี่ยนพอร์ต** (เช่น ถ้าพอร์ต 5000 ถูกใช้อยู่)

```bash
flask --app app run --port 8000
```

**เปิดให้มือถือในวง Wi-Fi เดียวกันเข้าได้**

```bash
flask --app app run --host 0.0.0.0
```

แล้วเปิด `http://<IP ของเครื่องคอมพิวเตอร์>:5000` บนมือถือ

> ⚠️ `python app.py` รันในโหมด debug เหมาะสำหรับใช้ส่วนตัวในเครื่องเท่านั้น
> หากจะนำขึ้นอินเทอร์เน็ต ให้ตั้ง `SECRET_KEY` ใหม่ ปิด debug และใช้ WSGI server เช่น `waitress` หรือ `gunicorn`
> (เว็บนี้ไม่มีระบบล็อกอิน ทุกคนที่เข้าถึงได้จะเห็นและแก้ไขข้อมูลได้)

## การแก้ไขเนื้อหา 7 ขั้นตอน

เนื้อหาทั้งหมดอยู่ในตัวแปร `STEPS` ใน `app.py` แต่ละขั้นมีโครงสร้างดังนี้

```python
{
    "no": 1, "icon": "🪷",
    "title": "ระลึกพระรัตนตรัย",
    "summary": "ข้อความสั้นที่แสดงบนการ์ดเสมอ",
    "blocks": [ ... ],                  # เนื้อหาใน “อ่านรายละเอียด”
    "link": ("mood", "ข้อความลิงก์"),    # ไม่บังคับ: ลิงก์ไปหน้าอื่น (mood / walk)
}
```

**ชนิดของ block ที่ใช้ได้**

| type | ใช้สำหรับ | รูปแบบข้อมูล |
|---|---|---|
| `p` | ย่อหน้าธรรมดา | `{"type": "p", "text": "..."}` |
| `chant` | บทสวดบาลี + คำแปล | `{"type": "chant", "lines": [("บาลี", "คำแปล"), ...]}` |
| `recite` | บทท่อง (`memorize: True` = มีโหมดฝึกท่อง) | `{"type": "recite", "title": "...", "memorize": True, "lines": ["...", ...]}` |
| `stages` | ลำดับขั้นมีหัวข้อ | `{"type": "stages", "rows": [("หัวข้อ", "คำอธิบาย"), ...]}` |
| `terms` | คำศัพท์ + ความหมาย | `{"type": "terms", "rows": [("คำ", "ความหมาย"), ...]}` |
| `map` | “ข้อความ … จัดเป็น …” | `{"type": "map", "rows": [("ข้อความ", "จัดเป็น"), ...]}` |
| `bullets` | รายการหัวข้อย่อย | `{"type": "bullets", "lines": ["...", ...]}` |
| `quote` | ข้อความเน้น | `{"type": "quote", "lines": ["...", ...]}` |

แก้ไขแล้วบันทึกไฟล์ — ถ้ารันด้วย `python app.py` เว็บจะรีโหลดเอง แค่รีเฟรชเบราว์เซอร์

**แก้รายการอารมณ์หรือระดับอารมณ์** ได้ที่ตัวแปร `MOOD_TYPES` และ `MOOD_LEVELS` ใน `app.py`

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| `ModuleNotFoundError: No module named 'flask'` | รัน `pip install flask` (ถ้าใช้ venv ต้อง activate ก่อน) |
| หน้าเว็บไม่มีสี / ไม่มีการจัดหน้า | ตรวจสอบอินเทอร์เน็ต — Tailwind โหลดจาก CDN |
| `Address already in use` / พอร์ต 5000 ถูกใช้ | เปลี่ยนพอร์ตด้วย `flask --app app run --port 8000` (บน macOS พอร์ต 5000 อาจชนกับ AirPlay Receiver) |
| ไม่มีเสียงระฆังเมื่อครบเวลา | ตรวจสอบว่าไม่ได้ปิดเสียงเบราว์เซอร์ และแท็บไม่ได้ถูกปิดเสียง |
| ติ๊กขั้นตอนแล้วหายไป | ต้องกด **💾 บันทึกการปฏิบัติ** ก่อนออกจากหน้า |
| `database is locked` | ปิดโปรแกรมอื่นที่เปิดไฟล์ `mindful.db` อยู่ แล้วลองใหม่ |
